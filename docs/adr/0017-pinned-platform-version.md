# 0017. Версия платформы PlatformIO закреплена

Статус: принято.

## Контекст

До 4.3.0 строка `platform` в `platformio.ini` была без версии, и релиз
собирался тем, что CI разрешал в день сборки. Локальная платформа 3.2.0 давала
образ реле 475 952 байта, а CI на 4.2.1 — 479 280: на 3,3 КБ больше при том же
исходном коде. Для платы с пределом OTA в 481 280 такая разница — это разница
между «влезает» и «нет». ESP-07S вышел с запасом 112 байт, и узнали об этом уже
из опубликованного релиза.

## Решение

Платформа закреплена: `platform = espressif8266@4.2.1`, в версии 4.3.1. Версии
библиотек закреплены по той же причине, поэтому рядом с ними и стоит комментарий
в `[esp8266]`. Образ, собранный на разных машинах из одного коммита, должен быть
одним и тем же образом, иначе проверка `OTA headroom` на машине разработчика
ничего не гарантирует про релиз.

## Последствия

Обновление платформы — осознанное действие: оно меняет размер каждого образа и
должно идти вместе с пересчётом всех строк `OTA headroom`, в первую очередь
самого тесного окружения. Сама смена платформы с 3.x на 4.2.1 в версии 4.3.1
обнажила и другую скрытую ошибку: новый SDK перестал терпеть режим флеша `qio`
на ESP8285 ([ADR 0016](0016-esp8285-flash-mode-dout.md)).

Источники: комментарий у `platform` в `platformio.ini`; коммит `ca6fb17`;
[CHANGELOG](../../CHANGELOG.md), секция 4.3.1; переход на платформу 4.2.1 --
Arduino core 3.0.2 → 3.1.2.
