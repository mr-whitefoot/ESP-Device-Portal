# 0002. Статический контракт конечного устройства

Статус: принято.

## Контекст

Реле и датчик используют одно ядро, но прошивка всегда содержит только одно
устройство. Runtime-подмена и виртуальные интерфейсы расходовали бы флеш без
практической пользы.

## Решение

Ядро вызывает функции `device::*`, объявленные в `core_contract.h`.
Окружение PlatformIO выбирает реализацию флагом `DEVICE_*`, а `src/main.cpp`
подключает один `lib/device_*`. Значения по умолчанию нет; неизвестная цель
останавливает сборку.

## Последствия

Новое устройство добавляется каталогом и окружением без изменения ядра.
Связывание не требует vtable. Порядок заголовков в unity-build становится
частью архитектуры, а UI-часть контракта остаётся связана с GyverPortal.
