# 0008. Общая версия для всех устройств

Статус: принято.

## Контекст

Изменения общего ядра одновременно попадают в реле и датчик. Раздельные линии
версий создавали видимость независимых кодовых баз, хотя релизы всё равно шли
парами.

## Решение

Хранить `release_version` один раз в общей секции `[esp01]`. Окружения
наследуют её и используют одновременно для `-DVERSION` и имени бинарника.
Тип устройства остаётся отдельной частью имени файла.

## Последствия

Версия описывает состояние общей кодовой базы, но не степень проверки
конкретного устройства. Правка только одного устройства всё равно повышает
общую версию; фактическую проверку каждого образа нужно описывать отдельно в
release notes.
