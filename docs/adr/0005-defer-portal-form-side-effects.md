# 0005. Отложенные побочные действия форм

Статус: принято.

## Контекст

GyverPortal вызывает обработчик формы до формирования HTTP-ответа. Смена
режима Wi-Fi или немедленная перезагрузка внутри обработчика обрывает POST, и
страница остаётся висеть. Для click-запросов порядок библиотеки отличается,
но две модели поведения создают лишний риск.

## Решение

Обработчик только сохраняет данные и заказывает действие. Новые Wi-Fi
credentials применяются автоматом после короткой задержки, перезагрузка —
через `RestartRequest` из конца `loop()`. Все дороги к перезагрузке используют
один механизм.

## Последствия

Форма успевает ответить браузеру. Пока перезагрузка ожидается, MQTT не
публикует периодические retained-сообщения, чтобы не вернуть данные, снятые
factory reset. Задержки и переполнение `millis()` закреплены native-тестами.
