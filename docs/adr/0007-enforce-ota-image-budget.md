# 0007. OTA-предел как критерий сборки

Статус: принято.

## Контекст

Разметка ESP-01 выделяет под скетч 962560 байт, но OTA записывает новый образ
рядом со старым. Образ может пройти обычную проверку размера, успешно
загрузиться по проводу и после этого больше никогда не обновиться по воздуху.
После добавления D1 mini единое число перестало быть корректным: её штатная разметка
с 4 МБ флеша допускает образ до 1044464 байт.

## Решение

Каждый профиль платы задаёт `custom_ota_max_size`: 481280 байт для ESP-01 и 1044464 байта
для D1 mini. `extra_script_ota.py` проверяет фактический `.bin` после его создания и завершает
сборку ошибкой при превышении предела выбранной платы.

## Последствия

Каждая выпускаемая сборка сохраняет возможность следующего OTA. Новая плата не может
заимствовать предел у другой: его нужно вывести из её разметки. Важна строка
`OTA headroom`, а не только стандартный отчёт Flash. Если SCons не создавал
новый BIN из-за идентичного машинного кода, post-action закономерно не
запускается.
