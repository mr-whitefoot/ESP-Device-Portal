# Правила работы с репозиторием

## Работа с физическими устройствами

- `Gate` не входит в область этого репозитория. Не менять для него код или
  конфигурацию, не собирать и не загружать прошивку без отдельного явного
  разрешения владельца именно на работу с `Gate`.
- Если проверка требует прошивки нескольких устройств, первым прошивать реле.
  Реле можно использовать для проверки изменений без дополнительного
  подтверждения владельца.
- Датчик DS18B20 прошивать только после явного подтверждения владельца на
  конкретное обновление и только стабильной сборкой. Диагностические,
  предварительные и непроверенные сборки на датчик не загружать.
- Адреса устройств и секреты не добавлять в репозиторий. Локальные адреса
  хранятся в `platformio_override.ini`, данные брокера — в
  `tools/broker.ini`; оба файла игнорируются Git.

## Проверка изменений

- Чистую логику проверять командой `pio test -e native`.
- Изменения общего ядра проверять сборкой обоих устройств:
  `pio run -e esp01_relay` и `pio run -e esp01_ds18b20`.
- Следить за строкой `OTA headroom` в выводе сборки. Успешная линковка без
  прохождения OTA-предела недостаточна для ESP-01.
- Перед работой с железом использовать чек-листы из
  `docs/runbooks/verification.md`.
